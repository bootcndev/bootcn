# Kbd

Shows keyboard keys and shortcuts in text.

## Usage

Wrap each key in `<kbd class="bootcn-kbd">`, and a combination in
`.bootcn-kbd-group`. Write the key names out where symbols may be unclear
("Ctrl" rather than "^").

## Accessibility

- `<kbd>` marks keyboard input; screen readers read the key names as text.
- Text keeps 4.5:1 contrast on the muted background.

## Dependencies

- Bootstrap 5.3+ CSS.
- `themes/tokens/tokens.css`.
