# Label

A text label for a form control, in the compact text-sm style.

## Usage

Always connect the label to its control with `for` and the control's `id`.
For a label with help text and errors, use the Field component.

## Accessibility

- Clicking the label focuses or toggles its control.
- The label is the control's accessible name; do not rely on placeholders.

## Dependencies

- Bootstrap 5.3+ CSS.
- `themes/tokens/tokens.css`.
- The `input` component.
