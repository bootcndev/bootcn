# Empty state

Fills an empty list or page with an icon, a short explanation and the next action to take.

## Usage

Show it where a list, table or page would be, when there is nothing to show
yet. Say why it is empty and offer the most useful next step.

## Accessibility

- The title is a heading, so users can find the state; pick the level that fits
  your page.
- The icon is decorative.

## Dependencies

- Bootstrap 5.3+ CSS.
- `themes/tokens/tokens.css`.
- The `button` component.
