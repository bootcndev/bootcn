# Typography

Readable styles for long-form text: headings, paragraphs, lists, quotes, inline code and tables.

## Usage

Wrap long-form content (articles, help pages, content from a CMS) in
`.bootcn-typography`; headings, paragraphs, lists, quotes, inline code and
tables inside it get consistent spacing. The helper classes `.bootcn-lead`,
`.bootcn-large`, `.bootcn-small` and `.bootcn-muted` work anywhere.

## Accessibility

- Keep heading levels in order; the styles do not change the structure.
- Links inside text are underlined, so they do not rely on color.
- Muted text keeps 4.5:1 contrast in both themes.

## Dependencies

- Bootstrap 5.3+ CSS.
- `themes/tokens/tokens.css`.
