Features

Everything you need to launch

Build pages people enjoy using, without fighting your tools.

  • Fast by default

    Static HTML and a few kilobytes of CSS. Pages load before anyone notices.

  • Accessible

    Keyboard support, labels and contrast are part of every component, in both themes.

  • Dark mode built in

    Every color is a token with a light and a dark value. Switch with one attribute.

  • Code you own

    Copy the files into your project and change anything. No package to update.

  • Responsive layouts

    Grids and navigation adapt from phones to wide screens without extra work.

  • No runtime surprises

    No framework and no build step in production, so nothing breaks on upgrade.
