# Call to action

A closing call-to-action panel with a headline, a short text and two buttons.

## Usage

Place it near the end of a landing page, before the footer. Keep the text
short and the first button for the action you want most.

## Accessibility

- The section is named by its `<h2>`.
- The grid pattern is decorative; text keeps 4.5:1 contrast on the muted
  background in both themes.

## Dependencies

- Bootstrap 5.3+ CSS.
- `themes/tokens/tokens.css`.
- The `button` component.
