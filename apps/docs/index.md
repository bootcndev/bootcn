
<div class="bootcn-features">
  <section>
    <h2>Your code, not a dependency</h2>
    <p>The CLI copies source files into your project. Edit them freely; there is no package to update at runtime.</p>
  </section>
  <section>
    <h2>Bootstrap-native</h2>
    <p>Built on Bootstrap 5.3 classes, plugins and CSS variables. Works next to the Bootstrap you already use.</p>
  </section>
  <section>
    <h2>Plain HTML and PHP</h2>
    <p>Made for server-rendered sites. Include the markup from PHP or paste it into HTML; no bundler required.</p>
  </section>
  <section>
    <h2>Accessible and tested</h2>
    <p>Keyboard and screen-reader behaviour, light and dark contrast and responsive layout are checked with Playwright and axe in three browsers.</p>
  </section>
</div>
