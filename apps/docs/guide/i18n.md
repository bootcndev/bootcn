# Translations

Labels, placeholders and help texts are in the HTML you install, so you
translate them like the rest of your page. A few texts are written by the
JavaScript: messages announced to screen readers ("3 suggestions.",
"Copied to the clipboard."), date segment names and a handful of button
names. Set them once per page, before the Bootcn scripts:

```html
<html lang="fr">
  <script>
    window.Bootcn = {
      messages: {
        'copy.done': 'Copié dans le presse-papiers.',
        'autocomplete.count.one': '{count} suggestion.',
        'autocomplete.count.other': '{count} suggestions.',
        'form.summary.one': 'Il y a 1 problème',
        'form.summary.other': 'Il y a {count} problèmes',
        'date-input.day': 'jour',
        'date-input.month': 'mois',
        'date-input.year': 'année',
        'date-input.placeholder.day': 'jj',
        'date-input.placeholder.month': 'mm',
        'date-input.placeholder.year': 'aaaa',
      },
    };
  </script>
</html>
```

Messages you do not set stay in English. `{name}` placeholders are filled in
by the script.

## Plurals

Keys that count something end in a plural category: `.one`, `.other`, and
for languages that need them `.zero`, `.two`, `.few` and `.many`. The
category comes from `Intl.PluralRules` for the page's `<html lang>`, so
Polish, Arabic or Russian get the right form.

## Messages

| Key                                                            | English                                         | Component                         |
| -------------------------------------------------------------- | ----------------------------------------------- | --------------------------------- |
| `copy.done`                                                    | Copied to the clipboard.                        | Code block, Conversation, Snippet |
| `autocomplete.count.*`                                         | 1 suggestion. / {count} suggestions.            | Autocomplete                      |
| `combobox.none`                                                | No results.                                     | Combobox                          |
| `combobox.count.*`                                             | 1 result. / {count} results.                    | Combobox                          |
| `combobox.selected`, `combobox.removed`                        | {label} selected. / {label} removed.            | Combobox                          |
| `command.none`, `command.count.*`                              | No results. / {count} results.                  | Command                           |
| `checkbox-group.min`                                           | Choose at least {min}.                          | Checkbox group                    |
| `form.summary.*`                                               | There is 1 problem / There are {count} problems | Form                              |
| `form.saved`                                                   | Saved.                                          | Form                              |
| `date-input.day` … `date-input.minute`, `date-input.dayPeriod` | day … minute, AM/PM                             | Date input                        |
| `date-input.placeholder.day` …                                 | dd, mm, yyyy, ––                                | Date input                        |
| `date-input.empty`, `date-input.range`                         | Empty / Choose a value in range.                | Date input                        |
| `date-range-input.count.*`                                     | 1 day selected. / {count} days selected.        | Date range input                  |
| `date-range-input.order`                                       | Check the dates.                                | Date range input                  |
| `image.unavailable`                                            | Image unavailable                               | Image                             |
| `prompt-input.send`, `prompt-input.stop`                       | Send / Stop                                     | Prompt input                      |
| `prompt-input.remove`                                          | Remove {name}                                   | Prompt input                      |
| `prompt-input.attached`, `prompt-input.removed`                | {name} attached. / {name} removed.              | Prompt input                      |
| `prompt-input.attached-count.*`                                | {count} files attached.                         | Prompt input                      |
| `tag-group.removed`                                            | {name} removed.                                 | Tag group                         |

Error texts set on the element (`data-error`, `data-error-value-missing`…)
win over these messages. Dates, months and AM/PM already follow the page
language through `Intl`; set `<html lang>` (or `data-locale` on a date
input).
